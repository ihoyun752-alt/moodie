## 1. 먼저 확인할 결론

1. **공식몰 4곳 모두 팔레트의 실제 색상·제형을 텍스트로 설명하지 않습니다.** 상세 설명은 이미지로만 제공되고, 텍스트로 확인되는 것은 옵션(구성) 이름과 전성분 항목에 적힌 칸별 색상 이름뿐입니다.
   - 따라서 **"대표 색상", "제형(매트·쉬머·글리터)", "무드 연결"은 공식 텍스트 근거가 없어 모두 미확인**으로 두었습니다. 색상 이름만 보고 색을 정하지 않았습니다.
   - 예외: 클리오 프로 아이 팔레트 에어의 "M20호, M21호는 … 올매트 팔레트" 문구 1건.
2. **팔레트 상품 수가 적습니다.** 브랜드별 공식몰의 팔레트 상품은 2aN 1개, 홀리카홀리카 3개, 투쿨포스쿨 2개, 클리오 1개입니다. 각 상품에 여러 구성(옵션)이 있어, 립의 "셰이드 1개 = 1행"처럼 **팔레트 구성 1종 = 1개**로 세어 후보를 만들었습니다.
3. **투쿨포스쿨은 서로 다른 구성이 2개뿐입니다.** 무드 스위치 팔레트와 아트클래스 프로타주 팔레트는 옵션(2호 소프티 핑크, 4호 휘핑 베리)과 칸별 색상 이름이 같아, 3개를 고르면 같은 색 구성이 중복됩니다. 무드 스위치 팔레트는 품절입니다.
4. **판매 상태가 불확실한 곳이 많습니다.** 2aN·투쿨포스쿨 페이지에 SOLD OUT 문구가 보이지만 옵션별 표시가 없어 확인 불가로 두었습니다(같은 쇼핑몰 플랫폼에서 반복되는 문구).
5. **홀리카홀리카 공식 주소(holikaholika.co.kr)는 enpranimall.com으로 연결**되며, 이 페이지의 한글이 깨져(인코딩 오류) 상품명·한글 옵션명을 정확히 읽지 못했습니다. 영문 색상 이름과 가격만 읽혔습니다.
