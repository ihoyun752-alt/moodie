# 추후 확장 아이디어

현재 구현 범위에 포함되지 않은 아이디어를 모아 둡니다. 핵심 기능과 구분해서 관리합니다.

## 핵심 기능 (우선 구현 대상)

1. 뷰티 프로필: 피부 타입, 피부 고민, 취향
2. 오늘의 무드 선택: 7가지 무드 (MOOD 페이지)
3. 맞춤 화장품 TOP 3 추천

## 확장 아이디어

### 트렌드 메이크업 챌린지

뷰티 콘텐츠 제작자들이 과장된 AI 메이크업 이미지를 참고해 실제 메이크업으로 재현하듯, 유행하는 스타일을 재미있게 따라 해 보는 콘텐츠입니다.

- 핵심 기능과 분리된 별도 콘텐츠로 둡니다. 예를 들어 나중에 메뉴에 `CHALLENGE`를 추가할 수 있습니다.
- 원본의 과장된 얼굴을 크게 보여 주지 않습니다. 작은 썸네일, 일러스트, 키워드 정도로만 참고합니다.
- 부담스럽거나 기괴한 느낌보다 **유머러스하고 친근하게 재해석**하는 방향으로 만듭니다.
- 실제로 따라 한 결과를 중심으로 보여 줍니다.

### NEW · BEST · ALL 페이지 확장

| 페이지 | 계획 |
|---|---|
| NEW | 신제품 탐색. 출시일 등 확인된 정보로 정렬합니다 |
| BEST | **출처가 확인된 랭킹 데이터**로만 인기 제품을 보여 줍니다. 데이터 출처를 화면에 표시합니다 |
| ALL | 카테고리별 전체 제품 탐색 (베이스, 아이, 립, 치크 등) |

### 그 밖의 아이디어

- 추천 결과에 "왜 이 제품인지" 설명 보여 주기 (무드, 피부 타입과의 연결)
- 선택한 무드를 기억해 다음 방문 때 보여 주기
- 검색, 장바구니 (헤더 아이콘은 현재 "준비 중")
