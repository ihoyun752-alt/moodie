# 제품 색상 초안 (검토용)

- 작성일: 2026-11-01. **검토용이며 CSV와 시뮬레이션에는 아무 색도 적용하지 않았습니다.** 승인한 색만 적용합니다.
- 기준: 브랜드 공식 홈페이지의 색상 정보만 씁니다. AI 생성 제품 이미지에서는 색을 뽑지 않았습니다.

## 1. 결론: 공식 색상값이 확인된 제품 0개

- 등록 때 확인한 공식 상품 페이지 기록(`review_notes`)을 다시 보면, **60개 제품 모두 셰이드별 색상값(HEX)이나 색상 설명 문구가 페이지 텍스트에 없습니다.** 색은 상세 설명 이미지(공식 발색 사진)에만 있습니다.
- 그래서 아래 표의 '공식 색상 정보'는 모두 **미확인**이고, 시뮬레이션에 쓸 수 있는 승인 색이 아직 없습니다.

## 2. 실제 색과 표시용 색의 구분 (관리 방법 제안)

| 구분 | 저장 위치 | 의미 |
|---|---|---|
| 실제 제품 색 | CSV `hex_color` + `hex_source` | 공식 표기(`official`) 또는 공식 발색 이미지에서 측정(`swatch-measured`)한 값. 설계 문서 규칙 그대로 |
| 시뮬레이션 표시용 색 | 새 파일 `data/simulation-colors.csv` (제안) | 캔버스 합성에 쓰는 색. 승인 여부·근거·`hex_color`와의 관계를 함께 기록. 화면에 '표시용 색'으로 표시 |

## 3. 공식 색을 확보하는 방법 (결정 필요)

1. **공식 발색 이미지에서 측정 (추천)**: 각 공식 상품 페이지의 상세 이미지 중 셰이드별 발색 사진을 내려받아 칸·발색 부분의 색을 측정하고, `hex_source=swatch-measured`, 측정 이미지 URL, 측정 위치를 기록합니다. 설계 문서가 허용하는 방식입니다.
   - 문제: 외부 이미지 저장 규칙상 `/tmp/moodie-image-review/`에만 저장해야 하는데, 이 폴더는 작업 폴더 밖이라 Claude가 열어 볼 수 없습니다(권한 설정 차단). **`docs/reference/official-swatches/`(Git 제외) 저장을 허락**해 주시면 진행할 수 있습니다. 검토 후 삭제합니다.
   - 문제: 공식 페이지에 셰이드별 발색 사진이 없는 제품(예: 2aN 베러미는 상세 영역에 배너만 확인)은 측정할 수 없습니다.
2. **담당자가 직접 지정**: 공식 발색 사진을 보고 담당자가 표시용 색을 정해 주시면 근거(본 이미지 URL)와 함께 기록합니다.
