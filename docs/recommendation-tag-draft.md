# 추천 태그 초안 (검토용)

- 작성일: 2026-11-01. **검토용 초안이며 `data/products.csv`에는 입력하지 않았습니다.** 승인한 값만 CSV에 반영합니다.
- 점수 단계: 설계 문서 6절의 `1.0` 대표 / `0.7` 잘 어울림 / `0.4` 함께 쓰면 어울림 / `0.1` 거의 안 어울림 / `0` 안 어울림. **`–`는 미확인(근거 없음)** 이며 점수를 매기지 않았습니다.
- 공식 홈페이지에는 립·치크·베이스·아이섀도우 모두 **셰이드별 색상 설명이 없었습니다**(상세 설명은 이미지). 그래서 근거는 아래 세 가지뿐입니다.
  1. 립·치크: **공식 옵션명(셰이드 이름)의 색 단어** — 근거 강도 '약함'. 색 단어가 없는 이름은 미확인.
  2. 아이섀도우: 등록 때 기록한 [임시 무드](옵션명·전성분 칸 이름 기반) + 담당자 색감 확인(2026-11-01, '대체로 일치') — 근거 강도 '중간'. 임시 무드를 아래 '무드 이름 대응'으로 7개 무드에 옮겨 `0.7`로 적었습니다.
  3. 베이스: 공식 문구의 피부 타입·고민. 무드 점수는 정책 결정 전이라 비워 둠.
- 열 순서: PURE 청순 · NUDE 누드 · MODERN 모던 · LOVELY 러블리 · CHIC 시크 · GLAM 글램 · HIP 힙

## 1. 먼저 결정해야 할 문제 (이대로면 추천 대상 0개)

승인 기준이 '세 점수 모두 검증된 제품만'이므로, 지금 초안으로는 **어떤 제품도 추천 대상이 되지 못합니다.**

| 문제 | 상태 | 제안 |
|---|---|---|
